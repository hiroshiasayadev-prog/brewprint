## What this is

Entry point for DRMCP product requirements that define the externally observable capabilities required from the MCP surface.

The current capability topics cover discovery and listing, retrieval, lexical search, and validation.

These requirements define what callers must be able to do. They do not define MCP tool names, request or response schemas, internal models, component boundaries, or implementation structure.
