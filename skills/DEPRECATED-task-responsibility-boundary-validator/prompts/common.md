C01. The Task owns one primary outcome aligned with its declared task type.
C02. The Task owns one completion judgment aligned with its primary outcome and declared task type.
C03. The Goal states the Task-owned primary outcome.
C04. The Work contains only actions needed to produce the primary outcome.
C05. The Work describes planned actions rather than an execution log.
C06. The Done condition defines one observable completion judgment for the primary outcome.
C07. The Verification confirms the Done condition without adding acceptance requirements.
C08. A supporting action from another task type owns no separate deliverable.
C09. A supporting action from another task type owns no separate completion judgment.
C10. All work in the Task shares one acceptance or verification boundary.
C11. All work in the Task can be completed by one owner.
C12. All work in the Task shares one release decision.
C13. All work in the Task shares one required independence boundary.
C14. The Task does not combine its primary outcome with a separate unresolved design decision.
