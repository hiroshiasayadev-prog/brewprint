T01. The Task owns one Investigation for one bounded research question.
T02. The Done condition requires the Investigation to satisfy its completion requirements.
T03. The Work assigns research, evidence, uncertainty, and options to the Investigation.
T04. The Work does not include adopting a decision.
T05. The Task does not own canonical artifact authoring.
T06. The Task does not own implementation.
T07. The Task does not own independent review.
T08. The Task does not own finding correction.
T09. The Task does not own lifecycle synchronization.
