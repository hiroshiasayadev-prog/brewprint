T01. The Task owns one bounded propagation of an already accepted result.
T02. The Done condition requires every named lifecycle, Evidence, completion-result, and relation update to express that result.
T03. Every writable target and propagated value is named in the Task.
T04. Every propagated value is mechanically derivable from accepted Evidence.
T05. The Task introduces no new design judgment or propagation choice.
T06. The Task does not create, remove, split, or reorder Tasks or Work Items.
T07. The Task does not author or repair substantive deliverables.
T08. The Task does not perform implementation, independent review, or correction.
