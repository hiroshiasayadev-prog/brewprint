T01. The Task owns one bounded parent-to-child Work Item decomposition outcome.
T02. The Goal states only the creation or split of child Work Item boundaries.
T03. The Work contains only actions needed to create or split child Work Items and record coarse parent-level routing.
T04. The Work does not perform or specify child-owned Tasks, deliverables, procedures, decisions, or reviews.
T05. The Done condition judges completion of the decomposition rather than completion of child Work Items.
T06. The Work does not change Task dependencies, blockers, owners, writer order, review order, or release order.
T07. The Task owns no separate implementation, review, correction, or synchronization outcome.
