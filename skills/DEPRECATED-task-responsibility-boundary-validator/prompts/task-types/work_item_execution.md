T01. The Task owns one referenced child Work Item as one parent-graph execution outcome.
T02. The Task identifies exactly one child Work Item through work_item_ref.
T03. The Goal and Work describe only the child Work Item's coarse purpose and parent-level execution role.
T04. The Work does not perform or specify child-owned Tasks, deliverables, procedures, decisions, or reviews.
T05. The Done condition requires completion of the referenced child Work Item.
T06. The Done condition does not separately require child-owned deliverables, judgments, or verification results.
T07. The Task does not create, split, redefine, or internally coordinate the referenced child Work Item.
T08. The Task owns no separate implementation, review, correction, or synchronization outcome.
