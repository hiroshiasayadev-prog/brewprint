T01. The Task owns one bounded decision ledger.
T02. The Done condition requires every owned decision item to have a terminal status.
T03. The Task does not own Investigation authoring.
T04. The Task does not own canonical ADR or Specification authoring.
T05. The Task does not own implementation.
T06. The Task does not own independent review.
T07. The Task does not own finding correction.
T08. The Task does not own final lifecycle synchronization.
T09. The Done condition does not depend on downstream ADR, Specification, review, or closure progress.
